How this works

01

Manuals are chunked & embedded

Each manual PDF is split into passages and turned into vectors with the Gemini embedding model, tagged with model name and page number.

02

Your question is matched

The question is embedded the same way, and the most relevant passages are pulled from a local vector store.

03

Gemini answers — grounded

Only the retrieved excerpts are handed to the model, with instructions to answer from them alone and say so when they don't cover something.

Built with FastAPI, ChromaDB, and the Gemini API — no LangChain, so every step above is a few lines of plain, readable code. View the source →
